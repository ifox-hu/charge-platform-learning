# 充电平台微信小程序

当前版本包含普通用户的模拟充电闭环：注册/登录、站点列表、站点详情、设备状态、选择空闲充电枪、启动订单、结束订单、自动计费和微信/支付宝模拟支付。

## 打开方式

用微信开发者工具导入本目录：

```text
E:\充电桩\charge-platform-learning\miniapp
```

开发环境默认请求：`http://localhost:8081/api`。地址集中在 `config/env.js`；真机调试时改成电脑局域网 IP，并在开发者工具中暂时关闭合法域名校验。

## 联调流程

1. 启动新项目后端 8081。
2. 打开小程序，进入登录页注册车主账号，或使用已有账号登录。
3. 登录成功后，首页请求 `GET /api/stations`。
4. 点击站点后请求站点详情、`GET /api/chargers?stationId=...` 和 `GET /api/connectors?chargerId=...`。
5. 在详情页点击“空闲”充电枪，输入车牌后启动模拟订单。
6. 在当前订单页结束充电，后端按分时电价返回费用。
7. 选择微信或支付宝并点击“确认模拟支付”，订单变为已支付。不会真实扣款。

请求封装会从微信本地存储读取 JWT，并自动添加 `Authorization: Bearer ...`。
