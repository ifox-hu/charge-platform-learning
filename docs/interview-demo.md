# 面试演示脚本

## 目标

用 5 分钟展示一条完整链路：设备在线 -> 启动充电 -> 实时状态 -> 停止结算 -> 异步事件 -> 审计记录。

## 演示前检查

- 打开 Web 地址，确认后端、Redis 和 RabbitMQ 状态正常。
- 确认 `SIM-PILE-001`、`SIM-PILE-002`、`SIM-PILE-003` 显示在线。
- 准备 `demo_admin / 123456`；公开环境只展示演示账号，不公开服务器凭据。

## 演示步骤

1. 在运营看板展示站点、设备、枪和当前订单统计。
2. 进入设备管理，说明 TCP 模拟桩会把枪状态同步到后端。
3. 选择空闲枪启动订单，输入一个测试车牌。
4. 回到看板或订单页面，展示实时功率、电压、电流和电量变化。
5. 停止订单，展示订单变为已完成并生成电费、服务费和总金额。
6. 打开操作审计，展示启动和停止操作的用户、接口、结果和时间。
7. 使用管理员打开消息监控，说明订单完成事件进入 RabbitMQ；失败重试超过次数后进入死信队列，可由管理员重试。

## 面试讲解重点

- 设备链路：TCP 接入模拟桩，状态写入数据库，再通过 WebSocket 推送 Web。
- 一致性：启动/停止订单使用事务和行锁保护枪状态，订单提交后才发布完成事件。
- 可靠性：RabbitMQ 主队列配置死信交换机，监听器失败经过重试后进入 DLQ，管理员页面支持查看和重试。
- 权限：JWT 认证，ADMIN 可管理资源和处理死信，OPERATOR 负责日常运营操作。

## 简历描述

基于 Spring Boot、Vue 3、MySQL、Redis、RabbitMQ 和 Docker Compose 开发充电桩运营平台；实现 Java TCP 模拟桩接入、WebSocket 实时状态推送、事务订单结算、分时电价、JWT 角色权限、操作审计及 RabbitMQ 死信重试，并通过 GitHub Actions 完成自动测试和远程部署。
