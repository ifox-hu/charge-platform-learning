# 充电平台启动与模拟桩联调

本文说明本项目本地开发时如何启动三台模拟充电桩、Spring Boot 后端、Web 前端，以及如何验证模拟充电链路。

## 一、启动前检查

确认以下文件已经存在：

```text
simulator/target/charge-platform-simulator-0.1.0-SNAPSHOT.jar
backend/target/charge-platform-learning-0.1.0-SNAPSHOT.jar
```

如果 JAR 不存在，需要先分别构建 simulator 和 backend。

## 二、启动顺序

建议按以下顺序启动：

```text
1. MySQL、Redis、RabbitMQ
2. 三台模拟充电桩
3. Spring Boot 后端
4. Web 前端或微信小程序
```

后端不会自动创建或启动模拟桩 Java 进程。后端启动后，如果 `9100`、`9101`、`9102` 没有监听，页面会显示设备离线。

## 二点一、首次启用地图坐标

如果数据库中的 `station` 表还没有坐标字段，请先执行：

```text
docs/db/V2__station_coordinates.sql
```

Web 地图首次解析站点地址后，会把高德 GCJ-02 坐标回写到站点记录；后续 Web 和小程序直接使用保存的坐标，不再按固定城市猜测位置。

## 三、启动三台模拟充电桩

在 PowerShell 中执行：

```powershell
cd 'E:\充电桩\charge-platform-learning'

$jar = (Resolve-Path '.\simulator\target\charge-platform-simulator-0.1.0-SNAPSHOT.jar').Path

if (-not (Test-Path $jar)) { throw "模拟桩 JAR 不存在：$jar，请先构建 simulator" }

Start-Process java -ArgumentList '-Dsimulator.port=9100','-Dsimulator.device-id=SIM-PILE-001','-Dsimulator.connectors=2','-Dsimulator.time-scale=60','-jar',$jar -WorkingDirectory (Split-Path $jar) -WindowStyle Hidden
Start-Process java -ArgumentList '-Dsimulator.port=9101','-Dsimulator.device-id=SIM-PILE-002','-Dsimulator.connectors=2','-Dsimulator.time-scale=60','-jar',$jar -WorkingDirectory (Split-Path $jar) -WindowStyle Hidden
Start-Process java -ArgumentList '-Dsimulator.port=9102','-Dsimulator.device-id=SIM-PILE-003','-Dsimulator.connectors=4','-Dsimulator.time-scale=60','-jar',$jar -WorkingDirectory (Split-Path $jar) -WindowStyle Hidden
```

三台设备对应关系：

| 设备 | 端口 | 充电枪 |
|---|---:|---:|
| `SIM-PILE-001` | `9100` | 2 把 |
| `SIM-PILE-002` | `9101` | 2 把 |
| `SIM-PILE-003` | `9102` | 4 把 |

确认端口：

```powershell
Get-NetTCPConnection -LocalPort 9100,9101,9102 -State Listen
```

看到三个 `Listen` 就表示模拟桩已启动。如果没有输出，说明模拟桩进程没有运行；先检查 JAR 路径和 Java，再重新执行启动命令。

## 四、在 IDEA 启动后端

在 IDEA 的后端运行配置中设置数据库和 JWT 环境变量：

```text
DB_HOST、DB_NAME、DB_USERNAME、DB_PASSWORD、JWT_SECRET
```

在 IDEA 中：

1. 执行 `File → Reload All from Disk`。
2. 顶部运行配置选择 `Backend Local`。
3. 点击绿色运行按钮。

运行配置还需要设置以下模拟桩连接参数：

```text
SIMULATOR_ENABLED=true
SIMULATOR_SYNC_DATABASE=true
SIMULATOR_HOST=127.0.0.1
SIMULATOR_PORT=9100
SIMULATOR_DEVICE_ID=SIM-PILE-001
SIMULATOR_DEVICES=SIM-PILE-001@127.0.0.1:9100,SIM-PILE-002@127.0.0.1:9101,SIM-PILE-003@127.0.0.1:9102
```

后端启动成功的标志：

```text
Tomcat started on port 8081
Started ChargePlatformApplication
```

也可以使用终端启动后端：

```powershell
cd 'E:\充电桩\charge-platform-learning\backend'

$env:DB_HOST = '你的数据库地址'
$env:DB_PORT = '3306'
$env:DB_NAME = 'charge_platform'
$env:DB_USERNAME = '你的数据库用户名'
$securePassword = Read-Host 'MySQL 密码' -AsSecureString
$env:DB_PASSWORD = [System.Net.NetworkCredential]::new('', $securePassword).Password
$env:JWT_SECRET = [Convert]::ToBase64String([Security.Cryptography.RandomNumberGenerator]::GetBytes(48))

$env:SIMULATOR_ENABLED = 'true'
$env:SIMULATOR_SYNC_DATABASE = 'true'
$env:SIMULATOR_HOST = '127.0.0.1'
$env:SIMULATOR_PORT = '9100'
$env:SIMULATOR_DEVICE_ID = 'SIM-PILE-001'
$env:SIMULATOR_DEVICES = 'SIM-PILE-001@127.0.0.1:9100,SIM-PILE-002@127.0.0.1:9101,SIM-PILE-003@127.0.0.1:9102'

java -jar '.\target\charge-platform-learning-0.1.0-SNAPSHOT.jar'
```

## 六、验证三台模拟桩是否接入后端

```powershell
$adminPassword = '123456'
$body = @{ username = 'admin'; password = $adminPassword } | ConvertTo-Json
$login = Invoke-RestMethod `
  -Uri 'http://localhost:8081/api/auth/login' `
  -Method Post `
  -ContentType 'application/json' `
  -Body $body

$headers = @{ Authorization = "Bearer $($login.data.token)" }

Invoke-RestMethod `
  -Uri 'http://localhost:8081/api/simulator/status' `
  -Headers $headers |
  ConvertTo-Json -Depth 10
```

正常结果中应看到：

```text
SIM-PILE-001 connected: true
SIM-PILE-002 connected: true
SIM-PILE-003 connected: true
```

## 七、验证 START、实时充电和 STOP

启动 `SIM-PILE-001` 的 1 号枪：

```powershell
$start = @{ command = 'START'; connectorId = 1 } | ConvertTo-Json
Invoke-RestMethod `
  -Uri 'http://localhost:8081/api/simulator/command/SIM-PILE-001' `
  -Method Post `
  -Headers $headers `
  -ContentType 'application/json' `
  -Body $start
```

等待几秒后再次查询状态，应看到：

```text
status: CHARGING
powerKw: 7.2
energyKwh: 持续增加
```

停止：

```powershell
$stop = @{ command = 'STOP'; connectorId = 1 } | ConvertTo-Json
Invoke-RestMethod `
  -Uri 'http://localhost:8081/api/simulator/command/SIM-PILE-001' `
  -Method Post `
  -Headers $headers `
  -ContentType 'application/json' `
  -Body $stop
```

停止后该枪应恢复为 `IDLE`。

## 八、Web 操作方式

在运营看板的“虚拟充电桩集群”区域：

- 在“模拟启动充电”中选择站点、充电枪和车牌号，点击“启动充电”。
- 充电订单中显示订单状态和实时结算数据。
- 订单页面点击“结束充电”：自动读取模拟桩实时 `energyKwh`，发送 `STOP` 后按真实电量结算，不再手动输入演示电量。

## 九、故障排查

### 1. 页面显示模拟桩离线

依次检查：

```powershell
Get-NetTCPConnection -LocalPort 9100,9101,9102 -State Listen
Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -match 'charge-platform-simulator' } | Select-Object ProcessId,CommandLine
```

三个端口都没有监听时，重新执行本节启动命令。端口正常但后端仍显示离线时，确认后端配置中的 `SIMULATOR_DEVICES` 与端口完全一致，并重启后端。

### 2. 后端接口返回 401

先登录获取 JWT，再访问 `/api/simulator/status`。当前账号为：

```text
admin / 123456
```

### 3. 端口被占用

查看占用进程：

```powershell
Get-NetTCPConnection -LocalPort 9100,9101,9102 -State Listen | Select-Object LocalPort,OwningProcess
```

确认是旧的模拟桩进程后，再按进程号停止，避免误停其他 Java 服务。

## 十、关闭服务

关闭后端 `8081`：

```powershell
$listeners = @(Get-NetTCPConnection -LocalPort 8081 -State Listen -ErrorAction SilentlyContinue | Where-Object OwningProcess -gt 0 | Select-Object -ExpandProperty OwningProcess -Unique)
$listeners | ForEach-Object { Stop-Process -Id $_ -Force }
```

关闭模拟桩时，按端口分别停止对应 Java 进程；不要使用全局 Docker 清理命令，以免影响 MySQL、Redis、RabbitMQ 和 MinIO。

如果数据库中的 `charge_order` 表还没有订单类型和归档字段，请先执行 `docs/db/V3__order_test_and_archive.sql`。该迁移会把现有订单标记为测试订单；之后 Web 和小程序的模拟充电请求会显式写入 `test_order=1`，真实业务请求应传入 `test_order=0`。订单清理接口会归档数据，不再物理删除。
