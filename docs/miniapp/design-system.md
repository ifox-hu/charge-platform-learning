# 小程序设计基线

## 当前基线

- 画布按微信原生竖屏布局实现，页面使用 `rpx`，固定操作区域留出底部安全区。
- 主色为深绿 `#183e2e`，强调色为荧光绿 `#b8ff5e`，背景为 `#f2f5f1`。
- 卡片、表单和状态反馈使用原生 WXML/WXSS，不引入第三方组件库。
- 登录、站点、充电桩、订单页面沿用相同的圆角、边框、间距和状态颜色。
- 地图使用微信原生 `<map>`，站点坐标来自后端，定位拒绝时回退到默认位置。
- 订单支付明确标注为模拟支付，不调用微信支付或支付宝真实支付。

## 已选方案：A 微信原生稳妥方向

- 采用浅色背景和白色表单卡片，保留深绿主色、荧光绿强调色。
- 登录页首屏只保留品牌、三步业务提示和账号表单，避免营销式大面积装饰。
- 注册页复用登录页结构，只增加昵称字段；登录和注册使用同一组原生输入控件。
- 站点页以地图和站点列表为主，充电枪页以状态列表和底部操作面板为主。
- 订单页以实时状态、功率/电流/电量和停止按钮为主；结束后显示模拟支付方式和支付状态。
- 关键按钮点击区域不小于约 88rpx，固定操作面板预留 `env(safe-area-inset-bottom)`。

## 组件映射

| 页面元素 | 小程序实现 | 状态处理 |
| --- | --- | --- |
| 登录/注册表单 | 原生 `input`、`button` | 空值、密码长度、请求失败、加载中 |
| 站点地图 | 原生 `map` | 定位成功、拒绝授权、默认位置、无坐标 |
| 充电枪列表 | `view` + 状态标签 | 空闲、充电中、离线、故障 |
| 订单实时状态 | `progress` + 文本 | 加载、充电中、停止失败、已完成 |
| 模拟支付 | `view` 选择器 + `button` | 微信/支付宝选择、处理中、已支付 |

原型和实际小程序均使用本地 WXML/WXSS，不依赖远程字体、脚本或图标资源。

## 关键数据映射

`/stations` -> 站点列表；`/chargers` 和 `/connectors` -> 设备与充电枪；`/customer/orders/start` -> 创建用户订单；`/customer/orders/{id}/live` -> 实时电量；`/customer/orders/{id}/stop` -> 结算；`/customer/orders/{id}/mock-payment` -> 模拟支付。

## 未验证项

静态文件检查已执行；微信开发者工具编译、安卓/iPhone 真机、体验版和正式发布尚未在本环境完成验证。真实微信支付没有配置，也不会作为当前演示结论。
